# История изменений

## 2.4.1 — 2026-10-08

- Распознавание использует только встроенные средства macOS: быстрые аудиофрагменты и системную диктовку.
- Удалён ненужный модуль облачной транскрибации вместе с его настройками и сетевым клиентом.
- Устаревший выбор движка автоматически заменяется поддерживаемым встроенным режимом.
- Очищены инструкции, описания архитектуры и шаблон сообщения об ошибке.

## 2.4.0 — 2026-10-08

Первый публичный релиз нового Dakt — помощника для разговоров.

- Системный звук через ScreenCaptureKit, без захвата микрофона.
- Локальная обработка коротких аудиофрагментов на macOS 26 и режим системной диктовки Apple Speech.
- Потоковые ответы GPT‑6 Luna через Responses API с отключёнными рассуждениями.
- Импорт резюме и генерация редактируемого шаблона встречи.
- Прозрачное масштабируемое окно, горячая клавиша и режим пропуска кликов.
- Исправлен замок после уменьшения окна. Открытие приложения и команда «Показать Dakt» возвращают управление.
- Универсальная сборка Apple Silicon / Intel, DMG с установкой перетаскиванием, контрольные суммы.
- Документация архитектуры, настройки и релизов; лицензия MIT.
- Подключение к корпоративному API использует выбранный локальный профиль без зашитого адреса организации.

### Ограничения

Быстрый локальный движок требует macOS 26 и установленной модели языка. Ответы требуют собственного доступа к API. Сборка не нотаризована Apple; приватный режим не гарантирует исключения из захвата всего экрана.
