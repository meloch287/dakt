# Участие в разработке

Спасибо за интерес к Dakt. Для ошибки или предложения сначала проверьте [существующие issues](https://github.com/meloch287/dakt/issues).

## Запуск

Нужны Xcode со Swift 6.2+ и SDK macOS 26:

```sh
swift test
./build.sh --out dist
open dist/Dakt.app
```

Для работы над интерфейсом используйте `--preview` и `--render-previews`: им не нужны API-ключи и доступ к экрану. Подробности — в [инструкции разработчика](Documentation/releasing.md).

## Изменения

1. Создайте отдельную ветку для одной задачи.
2. Воспроизведите исправляемую ошибку. Для поведения аудио, запросов, отмены и окон добавьте содержательную проверку.
3. Сохраняйте границы [модулей](Documentation/architecture.md). UI обновляется на MainActor; захват не должен ждать сеть.
4. Запустите `swift test` и `./build.sh --check`. Изменённый интерфейс проверьте при маленьком и большом размере окна.
5. Обновите связанные инструкции. В pull request укажите проблему, изменение и реально выполненные проверки.

Сообщения коммитов и основная документация — на русском; имена Swift-типов и методов — на английском.

## Данные для воспроизведения

Используйте синтетические аудиофразы и вымышленные резюме. Не коммитьте API-токены, ключи подписи, файлы из `~/.codex`, личные настройки или записи разговоров.

Работайте через fork и pull request. Изменения распространяются на условиях [MIT](LICENSE).
