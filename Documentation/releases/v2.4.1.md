Dakt 2.4.1 использует только встроенное распознавание macOS.

- Быстрые аудиофрагменты на macOS 26 и системная диктовка на прежних версиях macOS.
- Удалён ненужный модуль облачной транскрибации, его настройки и сетевой клиент.
- Устаревший выбор движка автоматически заменяется поддерживаемым режимом.
- Обновлены интерфейс, инструкции и архитектура проекта.

Скачайте **Dakt-v2.4.1-universal.dmg** и перетащите **Dakt** в **Applications**. Один образ содержит сборки для **Apple Silicon и Intel**.

Требуется macOS 13+. Для быстрого локального режима нужны macOS 26 и установленная модель языка. Для ответов нужен собственный доступ к Responses API.

Сборка не нотаризована Apple. Если macOS блокирует первый запуск, откройте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

[Настройка](https://github.com/meloch287/dakt/blob/main/Documentation/setup.md) · [Архитектура](https://github.com/meloch287/dakt/blob/main/Documentation/architecture.md)

```sh
shasum -a 256 -c Dakt-v2.4.1-universal.dmg.sha256
```
