Исправлена кнопка скрытия окна **«−»**.

- Клик срабатывает по всей области кнопки, а не только по тонкому символу.
- Кнопка принимает первый клик, когда Dakt неактивен.
- Скрытие работает при включённом замке. Остальные области окна продолжают пропускать клики к приложениям под ним.
- Прослушивание продолжается. **⌘⇧Space** возвращает окно и сохраняет режим блокировки.

Скачайте **Dakt-v2.5.1-universal.dmg** и перетащите Dakt в **Applications**. Образ содержит Apple Silicon и Intel. Требуется macOS 13+, для быстрого локального распознавания: macOS 26.

Сборка не нотаризована Apple. Если macOS блокирует первый запуск, используйте **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**.

```sh
shasum -a 256 -c Dakt-v2.5.1-universal.dmg.sha256
```
