Добавлен режим **IT-собеседование** для технических терминов и похожих сокращений.

- Общий словарь разработки, баз данных, сетей, тестирования и DevOps; можно добавить до 50 своих терминов.
- Названия известных технологий из резюме и контекста передаются как подсказки распознавателю и модели ответа.
- «Апи» и «эй пи ай» приводятся к API, «фаст апи» — к FastAPI. Явные IP-адреса сохраняются.
- Если в вопросе осталось неоднозначное IP, появляются короткие ответы для API и IP и кнопки выбора. Выбор термина уточняет вопрос и запускает новый ответ, отменяя текущий ответ и очередь.
- Дополнительных запросов к GPT на каждую фразу и загрузки новых речевых моделей нет. Потоковая выдача и режим без рассуждений сохранены.

Включите **Настройки → Распознавание собеседника → IT-собеседование**. Словарь не гарантирует безошибочного распознавания; неоднозначность обрабатывается по тексту. [Подробности и ограничения](https://github.com/meloch287/dakt/blob/main/Documentation/setup.md#it-словарь).

Проверены 89 автоматических тестов, нативное окно и три сценария через настоящий API: неоднозначное IP, явный IP-адрес и API в Python.

**Dakt-v2.6.0-universal.dmg** содержит Apple Silicon и Intel. macOS 13+, для быстрых локальных аудиофрагментов — macOS 26. Сборка не нотаризована Apple.

```sh
shasum -a 256 -c Dakt-v2.6.0-universal.dmg.sha256
```
